## 1. teacher 위험도 모델 재구현 (torchvision 충실 재현)

### 배경 — "거리뷰 위험도 판단 모델"의 정체 확인
PROJECT.md §4.4 의 teacher = ZenSVI perception "안전 인지" 모델. 실제 소스를 직접 확인:

- ZenSVI perception 은 **transformers / AutoModel / ImageProcessor 를 쓰지 않는다.** 전부
  **torchvision + `torch.load(.pth)`** 이다.
  - `ClassifierPerception` → `seshing/placepulse` (ResNet50, 224)
  - `ClassifierPerceptionViT` → `Jiani11/human-perception-place-pulse`
    (**torchvision `vit_b_16`, `IMAGENET1K_SWAG_E2E_V1`, 384** + 3-Linear/ReLU 헤드, 차원별 `.pth` 6개)
  - Global Streetscapes(glare 등) → torchvision MaxViT_T
- ZenSVI 에서 `AutoModel` 은 segmentation/depth/embeddings 에만 쓰이며 **위험도 모델이 아니다.**

### 중요 구분 — perceived safety ≠ 사고 위험
ZenSVI "safe" 차원은 **perceived safety**(사람이 "안전해 보인다"고 인지하는 정도, Place Pulse 2.0
군중 라벨)이며 **실제 교통사고 위험이 아니다.** 따라서 본 프로젝트의 teacher 는:

> **ZenSVI ViT 백본**을 가져와 **TAAS/KoROAD 사고 라벨로 새 헤드를 파인튜닝** → **사고 확률** 예측

즉 perceived-safety 점수를 그대로 쓰는 것이 아니라, 그 백본 위에 사고 위험 헤드를 얹어 학습한다.

### 재구현 내용 — `models/pm_risk_vit/`
- `PMRiskViT(nn.Module)` = **torchvision `vit_b_16`** (기본 weights `IMAGENET1K_SWAG_E2E_V1`, 384)
  + `heads=Identity`(백본=특징추출기) + **3-Linear/ReLU 위험 헤드**(768→512→128→1).
- `freeze_backbone=True`(기본): 백본 고정, **학습 파라미터 ~46만 / 전체 86.5M**(linear probe, §4.5-1).
- `PMRiskViTConfig`(dataclass): `backbone/weights/image_size/freeze_backbone/num_labels/head_hidden/dropout`.
- `default_transform` = `Resize((384,384))` + (train 시 `RandomHorizontalFlip`) + `ToTensor` + ImageNet
  정규화 — **ZenSVI ClassifierPerceptionViT 전처리와 동일**(224→384 로 정정).
- **`transformers` 의존성 제거**(perception 은 torchvision 이므로 불필요).

입력 형식: **단일 perspective 384 이미지 1장** → 로짓 1개. 지점당 4방위는 각각 독립 입력으로
넣어 방향별 사고 확률을 얻고 **지점 단위 평균**으로 집계(ZenSVI 표준 SVI 워크플로와 동일).

## 2. 학습 출력형 — 이진 사고 확률 + severity-weighted BCE

다중 클래스(심각도)가 아니라 **이진 사고 확률(0~1)** 을 출력한다. 이유:
- 다운스트림 `route_risk = 1 - Π(1 - p)` 가 **확률**을 요구.
- 데이터 희소(양성 86, 그 중 사망 6)라 다중클래스는 소표본에서 취약.

대신 심각도를 **손실 가중치**로 반영: `severity-weighted BCE`.
- `DEFAULT_SEVERITY_WEIGHTS = {경상: 1.0, 중상: 2.0, 사망: 3.0}` (대조 = 1.0).
- `PMRoadviewDataset(severity_weights=...)` → `__getitem__` 이 `(image, label, weight텐서)` 3-튜플 반환.
- `train_teacher` 는 `BCEWithLogitsLoss(reduction='none')` × per-sample weight → mean. `pos_weight`(클래스
  불균형)와 병행.
- `make_train_valid(severity_weights=...)` 는 **학습셋에만** 적용(valid 는 순수 지표).

**train / valid AUC 둘 다** epoch 별로 기록·출력하도록 수정(`history['train_auc']` 추가, 곡선 플롯).

## 3. 데이터 품질 결함 발견·수정 — 대조군 고속도로 누출

### 결함
시각화에서 대조(control) 이미지가 고속도로처럼 보여 실측 확인:
- 실제 manifest 대조점을 OSM 에 스냅한 결과 **대조군에 고속도로(motorway/trunk)가 혼입**:
  - daejeon **0 / 147** (깨끗)
  - **cheongju 5 / 102**, **sejong 1 / 9** (누출)
- 화면의 대조 4장 중 **2장이 실제 motorway**.

원인:
- `geo.load_drive_edges` 가 `network_type="drive"` 라 **고속도로/자동차전용도로까지 포함**.
- 소표본 지역(세종 사고 3건 등)은 exposure 분위수 bin 이 붕괴해 motorway 를 못 걸러냄.

문제: PM/이륜차가 진입 못 하는 고속도로가 대조군에 섞이면 teacher 가 "위험 vs 안전"이 아니라
"고속도로 vs 시가지"를 학습하는 교란.

### 수정
1. **`geo` 도로 제외 필터**: `EXCLUDED_HIGHWAYS = {motorway, motorway_link, trunk, trunk_link}` 를
   `load_drive_edges` 에서 제외(사고 스냅·후보·대조 모두 PM 주행 가능 도로로 제한).
   - 검증: cheongju 후보/대조 고속도로 **5 → 0** (highway edge 237개 제외).
2. **소표본 exposure 가드**: `exposure_bins = max(1, min(exposure_bins, n_pos // 5))` — 사고가 적으면
   bin 수를 낮춰 매칭 붕괴 방지.
3. **재수집**: 오염 캐시 제거 후 3지역 재수집(진행) → 깨끗한 manifest 재생성.

## 6. 검증 결과

| 노트북 | 상태 |
|---|---|
| `test_datasets.ipynb` | ✅ 재실행 0 에러(분포·지점지도·로드뷰 그리드) |
| `train_irl.ipynb` | ✅ 0 에러, 합성 가중치 복원(정규화 학습치 ≈ 진값), `PmCostWeights` 리터럴 출력 |
| `train_teacher.ipynb` | ✅ 깨끗한 데이터 학습 완료 — **valid AUC 0.786**(단일), **5-fold 0.741±0.050** |

- 모델/학습 코드 단위 검증: forward@384 `(B,1)`, 헤드 3층, severity 3-튜플·가중 BCE 역전파, GPU device
  경로 정상(evaluate 의 pos_weight CPU 정합 버그 수정).

### teacher 성능 (깨끗한 3지역, SWAG@384, frozen head, 20epoch, severity-weighted BCE)
- 데이터: train 1099 / valid 276 (총 1375장, 층화·지점그룹 분할)
- pos_weight = 2.9971
- best epoch = 1 (epoch 6 early stop) · **train AUC = 0.787 · valid AUC = 0.786**
- 5-fold CV: fold AUCs = [0.794, 0.646, 0.753, 0.743, 0.768] · **mean AUC = 0.741 ± 0.050**
- 해석: **오염(고속도로) 제거 + SWAG 사전학습 백본으로 0.607 → 0.786 향상.** train ≈ valid
  (0.787 ≈ 0.786)라 **과적합 없음**(frozen backbone + 작은 헤드의 일반화). "쓸만함(0.7~0.8)" 구간 진입.

> 당초 "고속도로 제거 시 쉬운 신호가 사라져 AUC 하락" 가능성을 우려했으나, SWAG 백본 효과가 더 커
> 실제 위험 구조 학습으로 오히려 상승. 양성 86 은 여전히 소표본(CI 넓음) → 확장(§4)이 성능 레버.
